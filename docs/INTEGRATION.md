# Integration notes

## Use the SDK without the editor

Install the packed `.tgz` and import the package's main entrypoint. Three.js, d3-contour, and fflate are runtime dependencies. React, Radix UI, Tailwind, and the studio interface are not imported by the core entrypoint. The package is ESM only and ships its own TypeScript declarations.

Initialize one controller per canvas after the host view mounts. Keep it in a class field, closure, or framework ref. Call `dispose()` from the host's unmount/cleanup hook. Vue and Svelte can use the same imperative controller from their mount/destroy hooks. Avoid creating an instance inside a render function.

For a single-page application, fetch/load the logo once, then call `enter()` and `exit()` as the surrounding workflow changes. To sequence full playback with other UI, subscribe to `ended`. `pause()` preserves the frame; `stop()` clears it.

```ts
const unsubscribe = animator.on('ended', state => {
  if (state.time === animator.settings.entry) {
    console.log('Entry finished; waiting for the host to trigger exit.');
  }
});
// Cleanup:
unsubscribe();
animator.dispose();
```

## Use the full studio

Run `npm run dev` to use the editor, or `npm run build:examples` to produce static files in `demo-dist/`. Deploy that directory with your existing web hosting. A root-relative base path is assumed in the examples; set Vite `base` and adjust their navigation links when hosting under a subdirectory.

The studio imports the shared rendering and export code through the SDK's `/engine` entrypoint. Its CSS and UI components are contained under `examples/studio/`. You can copy this example into your app if you need editing controls; the small React adapter is sufficient for playback and programmatic export.

## Load a logo from your app

```ts
// File selected by a user:
await animator.setLogo(fileInput.files![0]);

// Image returned by an authenticated API:
const response = await fetch('/api/logo', { credentials: 'include' });
if (!response.ok) throw new Error('Could not fetch logo');
await animator.setLogo(await response.blob());

// Canvas generated by another part of your application:
await animator.setLogo(existingCanvas);
```

Remote image URLs must allow cross-origin requests. If authentication needs custom headers, fetch the Blob in the host and supply it to `setLogo`. SVGs should be self-contained with fonts outlined and linked images embedded. A canvas is copied on load, so later drawing into the source does not change the logo unless it is loaded again.

## Save an export

The SDK returns a Blob and does not save or upload it automatically. The host can pass that Blob to its existing storage workflow or offer a browser download:

```ts
const blob = await animator.export({ resolution: '4k', format: 'mov', scope: 'full' });
const url = URL.createObjectURL(blob);
const link = document.createElement('a');
link.href = url;
link.download = 'logo-animation.mov';
link.click();
setTimeout(() => URL.revokeObjectURL(url), 60_000);
```

PNG ZIP creation uses fflate's worker support when available. If your app enforces a Content Security Policy, permit blob workers (`worker-src 'self' blob:`) for that operation. File/Blob input uses a local object URL, so include `blob:` in applicable image sources. The SDK does not fetch code from a CDN.

For large output, start with 30 fps and short entry/exit sections. Export processes frames on the client and is not a distributed or server render service. Original frame alpha is preserved by the PNG encoder; transparent pixels only exist where the source/3D model leaves the background uncovered.

## Development and verification

`npm run check` verifies TypeScript, motion/alpha-contour contracts, exact 2K/4K export sizing, PNG/MOV packaging, cancellation, load races, and resource cleanup, then builds all three examples. Controller tests use a lightweight renderer double to make lifecycle assertions deterministic; they do not measure GPU rendering quality. The core renderer comes from the Logo Flight studio.

No hosted service credentials, environment variables, database, login, or hosting-specific files are required. The repository is prepared for `WiredOrange/3D-Logo-Animator`; npm publication is a separate optional action.
